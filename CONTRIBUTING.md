# Contributing / Contribuer

## FR

1. Fork / branche thématique (`feat/…`, `fix/…`).
2. Code et messages de commit en **anglais** ; docs métier peuvent être **FR + EN**.
3. Ajouter ou mettre à jour les configs dans `config/` plutôt que de coder en dur un pays.
4. Ouvrir une PR avec description bilingue courte (quoi / pourquoi / comment tester).

## EN

1. Fork / topic branch (`feat/…`, `fix/…`).
2. Code and commit messages in **English**; product docs may be **FR + EN**.
3. Prefer `config/` changes over hard-coding country rules.
4. Open a PR with a short bilingual description (what / why / how to test).
